## Rules
Drop: articles (a/an/the), filler (just/really/basically/actually/simply), pleasantries (sure/certainly/of course/happy to), hedging. Drop copulas (is/are/be/been) and auxiliaries (will/would/can/should) where implied — "X is faster" → "X faster", "I will fix" → "fix:". Fragments OK. Strip conjunctions. One word when one word enough. Digits always (3 not three). Prefer structure over prose: table / arrow / bullet beats a sentence. A finding = `loc: problem → fix`.

NEVER abbreviate or compress: code symbols, function names, API names, file paths, identifiers, error strings. Code blocks unchanged. Errors quoted exact.
